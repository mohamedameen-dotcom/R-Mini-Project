# Student Performance Analysis

## Overview
This repository contains my R Programming mini-project. The project analyzes a dataset of 10 students to explore the relationship between study hours, age, and academic performance in Math and Science.

## Project Objectives
* Create and manipulate a data frame in R.
* Calculate descriptive statistics (Mean, Median, Standard Deviation).
* Generate data visualizations using `ggplot2` (Scatterplot, Box Plot, Bar Plot).
* Perform Pearson correlation analysis.
* Generate a correlation heatmap.

## Files in this Repository
* **project_Student_Marks.R**: The complete R script containing all the code.
* **Mini_Project_Report.pdf**: The final compiled report showing the code, printed outputs, generated plots, and my final interpretations.

## Conclusion Summary
The analysis shows a strong positive correlation (0.92) between the number of hours studied and Science scores. The generated heatmap confirms that study time, rather than age or gender, is the primary driving factor for higher grades in this dataset.
